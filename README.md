# [NINJA SURVIVOR]

My first completed Unity game and the project that helped me win **1st place in a game development competition** held in another city.

## About

A fast-paced 2D action game where the player must survive waves of enemies, move across the map using parkour abilities, fight different enemy types, and achieve the highest possible survival score.

The game was developed as a complete playable project with multiple gameplay systems, progression, saving, localization, and hidden easter eggs.

## Features

* Player movement and combat
* Parkour system with wall climbing
* Wave-based enemy spawning
* Survival timer
* Boss fight
* Health and healing system
* Collectible healing items appearing on the map
* High-score system
* Saving high scores
* Pause system
* Main menu
* Weapon and character skin shop
* In-game currency and loot system
* Multiple enemy factions and enemy types
* Russian, English, and Turkish localization
* Hidden easter eggs and interactive objects
* One fully playable map

## Enemy Types

The game contains three main enemy categories:

### Ground Enemies

Move around the map and attack the player at close range.

### Flying Enemies

Cannot be killed. They explode on contact with the player and always deal damage.

### Ranged Enemies

Stay in place and attack the player from a distance.

The game includes multiple enemy variants, including:

* Ogre
* Ferva
* Blue
* Bullet
* Meteor
* Machine Gunner
* Arrow Launcher
* Laser Cannon

## Progression & Economy

Ground enemies can drop **scrap** when defeated.

Scrap can be exchanged in the shop for new weapon skins.

The game also includes a currency system and a skin shop, giving the player a simple progression loop between runs.

## Easter Eggs

The map contains several hidden interactions:

* **Insulting Robot** — a hidden robot that curses at the player and wishes for them to die.
* **Ball** — a ball that can be kicked around the map.
* **Radio** — interacting with the radio can trigger music or hidden sounds.
* **Secret Room** — a hidden room can be accessed by passing through a wall in the upper-right part of the map.

## Development

This was my first completed game and one of my earliest large Unity projects.

At the time, I was still learning about pixel-art consistency and game production, so the project has some visual inconsistencies in pixel scale between the background, characters, and other assets. I consider this part of the project's development history and learning process.
